# 🏙️ GitCity — 3D Codebase Cartography

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Three.js](https://img.shields.io/badge/Three.js-0.160.0-black.svg)](https://threejs.org/)
[![GitHub Pages](https://img.shields.io/badge/Deployment-GitHub%20Pages-brightgreen.svg)](https://sadmandied.github.io/git-city-3d/)

> **Transform any GitHub repository into an interactive 3D architectural city.**  
> Directories form elevated district plinths, files become architectural monoliths, and an interactive commit timeline reconstructs the project over time.

---

## 🌟 Highlights

- **🏛️ Architectural Cartography:** Directories become clean campus plinths; files become modern matte monoliths scaled proportionally to size and lines of code.
- **🎨 GitHub Language Palette:** Subtle, restrained color hierarchy adhering to official language palettes (TypeScript Azure, JavaScript Gold, Python Sky, Java Amber, Vue Emerald, Rust Coral).
- **⏳ Commit Timeline:** Scrub through git history to watch the codebase assemble chronologically.
- **🔍 Cursor Hover & Inspector:** Hover over buildings for instant file previews; click to smoothly glide the camera and view detailed metrics.
- **🛰️ Cinematic Orbit Tour:** Single-click architectural drone flight with smooth camera navigation.
- **⚡ Zero Build Dependencies:** Pure standard ES Modules. Runs instantly in any modern browser without bundlers or build steps.
- **🚀 Dual-Mode GitHub API:** Explore live public repositories with automatic fallback to built-in datasets.

---

## 🏗️ Codebase Mapping

| Code Concept | Architectural Representation |
| :--- | :--- |
| **Directory / Folder** | Precision-milled architectural plinth with subtle monospace labels |
| **File** | Matte architectural skyscraper with language-tinted crown |
| **Lines of Code (LOC)** | Building height and mass |
| **Language** | Roof crown tint and subtle edge accents |
| **Git Commits** | Chronological timeline playback |

## 🚀 Quick Start

### 1. Run Locally
```bash
git clone https://github.com/sadmandied/git-city-3d.git
cd git-city-3d
python main.py
```
*Opens automatically on `http://localhost:8080`.*

### 2. Live GitHub Pages
Explore directly online:  
👉 **[https://sadmandied.github.io/git-city-3d/](https://sadmandied.github.io/git-city-3d/)**

## 🎮 Controls

| Action | Input |
| :--- | :--- |
| **Orbit / Rotate** | Left-Click + Drag |
| **Pan** | Right-Click + Drag (or Shift + Left-Click) |
| **Zoom** | Scroll Wheel |
| **Hover Preview** | Move cursor over any skyscraper |
| **Inspect Building** | Click any skyscraper |
| **Reset View** | Click Reset Camera icon in top bar |
| **Drone Tour** | Click Tour in top bar |
